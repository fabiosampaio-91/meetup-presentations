# Meetup Presentations

Decks for the community meetups I organise, one folder per meetup:

```
<Community> Presentations/YYYY-MM-DD - <Meetup Name>/   deliverables (pptx, pdf, web, assets, deck.json)
Sources/YYYY-MM-DD - <Meetup Name>/                      organised source material for that meetup
tools/build_deck.py                                      builder (PPTX + PDF + web from deck.json)
docs/                                                    GitHub Pages: web decks + PDFs
.claude/skills/meetup-presentation/                      the repeatable procedure
```
